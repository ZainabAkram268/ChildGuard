# ChildGuard

## 🌟 Project Overview
ChildGuard is a comprehensive web platform dedicated to eradicating child labor by connecting underprivileged children with sponsors and donors. Our mission is to create a world where every child has access to education, healthcare, and opportunities for a brighter future.

## 🎯 Our Mission
To eliminate child labor through strategic interventions including education sponsorship, family support programs, and community awareness campaigns. We believe every child deserves the right to childhood, education, and proper development.

## 💡 Key Features

### 🔐 User Management
- User registration and authentication
- Secure login system
- Profile management

### 👥 Child Profiles
- Add and manage children's records
- Track child information and status
- Update child progress

### 💰 Sponsorship System
- Donor registration and management
- Sponsor-child matching
- Payment tracking

### 📊 Dashboard & Analytics
- Admin dashboard for monitoring
- Statistics and reports
- Progress tracking

### 🛡️ Security Features
- Data protection and privacy
- Secure authentication
- Role-based access control

## 🛠️ Technical Stack
- **Backend**: Node.js with TypeScript, Express.js
- **Database**: SQLite with proper ORM
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Authentication**: JWT based secure login
